# Firmware player

`backflip_player.c` / `.h` is a dependency-free keyframe player (C99, no heap, no libm) for 12-servo quadrupeds. `presets/*.h` are the tables from [`../presets`](../presets), generated by `python scripts/export_c.py`.

```c
#include "backflip_player.h"
#include "presets/k7_405.h"

static bf_player_t flip;

void backflip_button(void)                         /* e.g. from a web handler or a button */
{
    uint16_t stand[12];
    read_servo_positions(stand);                   /* your driver: present position, ticks 0..1023 */
    set_servo_gains_strong();                      /* stiff position loop for the flip */
    if (bf_start(&flip, &BF_K7_405, stand, millis()) == BF_ERR_RAIL)
        printf("refused: servo %d would pass its end stop by %d ticks in frame %d\n",
               flip.rail_servo, flip.rail_over, flip.rail_frame);
}

void servo_task_every_5ms(void)                    /* the loop that owns the servo bus */
{
    uint16_t t[12];
    if (flip.playing) {
        if (bf_tick(&flip, millis(), t)) send_servo_targets(t);
        else restore_servo_gains();
    }
}
```

Servo order is 1..12 = front-right hip/thigh/knee, front-left, rear-right, rear-left (Mini Pupper numbering). Ticks: 1024 per 310°, so 0.3027° per tick.

Check it on a PC (the test suite does this and compares every tick with the Python player):

```
make -C firmware/host
./firmware/host/play_table k7_405 | head
```
